# Curriculum Reference Matrix

The curriculum is authored as an original learning system. External standards inform scope and sequencing; the app does not copy textbook pages or proprietary question banks.

| Layer | Design target | Implementation |
|---|---|---|
| Kana | Read and write hiragana/katakana before JLPT chapters | Kana foundation at the top of Learning |
| JLPT N5-N1 | Progressive grammar, vocabulary, kanji, reading, listening, speaking, writing, review | Level -> Chapter -> Sub-chapter -> Activity |
| Practical Japanese | Everyday tasks and real communication | Context lessons, dialogs, documents and review |
| JFT-Basic | Script/vocabulary, conversation/expression, listening, reading | Separate practice track |
| SSW / Work in Japan | Job-context Japanese | Work track with reusable lesson references |
| Mastery | Retrieval, spaced review, weak-skill targeting | Adaptive engine + review queue |
| Assessment | Skill checks without locking ordinary lessons | Quiz Center, unit tests and mock tests |

Current depth target: approximately 20+ chapters per JLPT level, with six sub-lessons in each depth unit, plus the original foundational units already present in the repository.

## Standards consulted

- JLPT official information: https://www.jlpt.jp/e/
- Japan Foundation JFT-Basic: https://www.jpf.go.jp/jft-basic/e/
- Japan Foundation JF Standard: https://www.jpf.go.jp/e/project/japanese/education/

These references are used for scope and competency alignment, not as a source for copying proprietary lesson text or test items.
