# UI cleanup and deep curriculum

## Product changes
- Library is a reference/tool space, not a second Learning area.
- Remove `Vocab lanjutan` entry from Library.
- Remove ad slots from the Library/Study experience.
- Remove the `Rekomendasi langkah berikutnya` card.
- Remove `Learning aktif` from Library.
- Learning Path is the single home for structured course progression.
- Donation leaderboard is ranked by donated amount, highest first, and emphasizes total amount.
- Each chapter must expose a substantial set of lessons/materials rather than a short placeholder list.
- Each lesson should support clear `Lanjut` navigation into the next lesson/chapter.

## UX direction
Inspired by the supplied Busuu-style references: structured vertical course roadmap, chapter groupings, rich lesson cards, visible progress, and persistent next-step navigation.
