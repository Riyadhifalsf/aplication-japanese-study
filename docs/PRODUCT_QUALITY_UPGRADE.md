# Product Quality Upgrade — 2026-09-09

Dokumen ini mencatat peningkatan lintas fitur yang menjadi baseline UX aplikasi.

## Learning
- Kana foundation (Hiragana + Katakana) hadir sebelum Bab 1.
- Materi pada level aktif N5–N1 dapat dijelajahi bebas; lock dipakai hanya untuk state/rekomendasi bila dibutuhkan, bukan untuk mencegah lompat lesson di level aktif.
- Struktur materi: Level → Bab → Sub-bab/Micro-lesson → aktivitas → review → assessment.
- Pengguna tetap mendapat jalur rekomendasi adaptif tanpa kehilangan kebebasan eksplorasi.

## Home
- Streak dan Kanji hari ini diprioritaskan di bagian atas.
- Shortcut horizontal untuk Quiz Center, Misi, Kana, Kanji, Grammar, Kotoba, dan Reading.
- Weekly Learning Pulse memperlihatkan ritme aktivitas 7 hari terakhir.

## Library
- Library adalah katalog materi/rujukan. Quiz dan Exam diarahkan ke Quiz Center.
- Library mempertahankan full catalog lintas level walaupun Learning mengikuti level aktif pengguna.

## Profile
- Activity History tidak dihapus; tersedia filter tahun.
- Statistik mencakup XP, streak, Kanji dipelajari/dikuasai, kosakata dikuasai, akurasi quiz, hari aktif, waktu aktif, dan grammar selesai.
- Achievement Gallery memakai milestone progres nyata.

## Settings & Support
- Liquid Glass adalah mode UI nyata untuk surface Settings.
- Level materi mengontrol katalog Learning; Library tetap penuh.
- Dukungan komunitas masuk melalui Donasi, dengan total donor dan leaderboard saat backend transaksi aktif.

## Prinsip baru
1. Jangan mengunci pengetahuan yang secara pedagogis boleh dieksplorasi.
2. Pisahkan materi, latihan, dan assessment agar navigasi mudah dipahami.
3. Gunakan progress yang dapat diverifikasi untuk badge dan insight.
4. Semua statistik harus tetap berguna saat offline.
5. UI yang bergantung pada backend harus graceful ketika data server belum tersedia.
