# Curriculum Depth Specification

Setiap level N5–N1 terdiri dari unit/bab yang memiliki sub-bab/lesson mandiri. Lesson tidak dikunci oleh lesson sebelumnya; urutan hanya rekomendasi.

Struktur setiap bab:
1. Tujuan belajar
2. Konsep dan penjelasan inti
3. Kosakata kontekstual
4. Tata bahasa/pola
5. Contoh kalimat
6. Pelafalan dan listening
7. Kanji terkait
8. Latihan terarah
9. Review dan kesalahan umum
10. Kuis penguasaan
11. Bacaan/dialog kontekstual
12. Ringkasan bab

UI Learning menampilkan bab sebagai node path dan saat node dibuka menampilkan seluruh sub-bab sehingga pengguna dapat memilih sub-bab mana pun.

Level aktif pengguna menentukan level materi yang tampil di Learning. Library tetap menampilkan seluruh katalog N5–N1 tanpa dibatasi level aktif.
